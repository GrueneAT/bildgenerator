01Strategy

Three low-coupling changes on top of merged z6qfk.

Strategy summary

The Barlow font infrastructure from z6qfk is already in place. This issue mostly adds a second font to existing machinery and re-introduces a tiny picker that was previously removed. The text font is hardcoded today at event-handlers.js:141; there is no picker in the DOM.

  • Feature 1 (logo hint) is pure markup.

    A Tailwind hint in the Step-1 logo block (index.html:636-652). No JS. The value="" option is the „kein Logo“ path; users then use „Bild hinzufügen“ (index.html:910-913).

  • Feature 2 (Vollkorn + descriptive picker) is the core work.

    Add a 2-option select to the Step-3 text section, an OPTIONS map to constants.js, read it in #add-text, re-render via the existing loadFont(), add a Vollkorn Google-Fonts <link>, and extend the FontFaceObserver preload.

  • Vollkorn is a serif — must preload or it falls back.

    The single riskiest spot is preloadFonts() (wizard.js:22), which binds every preload entry to the single Barlow family. It must carry a family per entry for Vollkorn to preload at all.

  • Feature 3 (examples page) is a new root static page.

    Mirror impressum.html; createStaticPage() (build.js:107) already copies it to build/. Style it with the hosted flomotlik design system; link it from the picker hint.

03Decisions

Key decisions & options

Where the font picker lives

Chosen

Step-3 „Text hinzufügen“ section, before #add-text (index.html ~line 887), using the existing gat-select text-method w-full classes.

Advanced options panel (Step 4) — further from the text input it controls; worse discoverability.

Vollkorn weights / italic

400 + 900 upright

Match the design-system import Vollkorn:ital,wght@0,400;0,900. No italic is actually loaded there.

Requesting italic (1,...) — the DS doesn't load it; Fabric would fall back or load an unused descriptor.

Final accent canvas weight (400 vs 900)

Open

Both are loaded. Recommend 900 for visual parity with the heavy default; planner pins one in OPTIONS.

preloadFonts() second family

Watch

Carry a family per PRELOAD_FONTS entry (or add a second loop). Naively appending Vollkorn entries binds them to Barlow (wizard.js:22) — Vollkorn never preloads.

Example image generation

Open

Commit pre-rendered app-output PNGs under resources/images/ (deterministic, simplest).

Generate via the visual-regression harness on every build — more moving parts for a static help page.
