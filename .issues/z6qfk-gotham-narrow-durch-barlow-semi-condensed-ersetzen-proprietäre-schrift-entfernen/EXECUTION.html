01Strategy

Read this first — the rest is detail.

Strategy summary

Gotham Narrow is gone. The runtime now loads Barlow Semi Condensed from the Google Fonts CDN with explicit numeric weights, and all four vendored .otf files are deleted — no proprietary font, no vendoring. Tasks 1–5 completed and verified; Task 6 (brand sign-off) is a human checkpoint and is deliberately left open.

  • Weight, not just family.

    Gotham used four distinct @font-face family names; Barlow is one family + weights. Explicit fontWeight (text 900, logo 800) was added at every Fabric.js text site — a bare family swap would have rendered everything Barlow 400.

  • Font present in the tested build.

    The Google-Fonts <link> sits beside the design-system CDN link in both index.html and impressum.html, so it survives into build/, which is what the visual suite serves.

  • Baselines regenerated.

    Barlow is narrower, so 24 of 76 visual-regression baselines shifted; all were regenerated and the suites pass with zero font-fallback warnings.

03Decisions

Key decisions & options

Stale compiled Tailwind (output.css)

Auto-fixed

The committed resources/css/output.css still had the Gotham @font-face baked in; npm run build bundles but does not recompile Tailwind. Ran npm run build-css-prod to recompile from the cleaned input.css and amended it into the Task 3 commit (e3cf64f) — without this the repo grep gotham gate would not stay clean.

Playwright headless-shell rev 1194

Environment only

The project pins Playwright 1.56.1 (needs chromium-headless-shell rev 1194); the image only shipped rev 1223 and the project installer hung on arm64. Fetched the official 1194 zip via curl, extracted with system unzip, wrote the install markers. No repo or package.json change.

Constants comments rephrased

Spec adjustment

The plan's literal constants.js block carried // was Gotham … comments that would have tripped the grep-clean gate. The documented weight mapping was kept; comments were rephrased to role-based descriptions (e.g. // default canvas text (Black)).

Open — Task 6

Does Barlow 900 default text read heavy enough vs the old Gotham Ultra, and is the logo (800) clearly lighter? 900 is the heaviest Barlow weight; the only remaining hierarchy lever is WEIGHT_LOGO in resources/js/constants.js. Review the regenerated samples under visual-regression/reference-images/.
