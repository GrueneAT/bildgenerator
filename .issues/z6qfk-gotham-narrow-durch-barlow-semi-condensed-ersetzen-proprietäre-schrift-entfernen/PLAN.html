01Strategy

Strategy summary

Replace the proprietary, vendored Gotham Narrow font with the free Barlow Semi Condensed (Google Fonts CDN), then regenerate every visual-regression baseline. The pivot: Gotham was four @font-face family names; Barlow is one family with numeric weights — so the code, which selects fonts purely by fontFamily string and never sets fontWeight, must gain explicit weights or every headline silently renders Barlow 400 (thin).

  • Structural swap, not a string find-replace.

    Set fontFamily: "Barlow Semi Condensed" AND add fontWeight (900 text / 800 logo) and fontStyle for the italic preload at every Fabric.js selection site.

  • Font must reach the production build before references flip.

    The visual suite runs against build/; scripts/build.js rewrites the CSS <link> run, so the Google-Fonts link must sit ABOVE the FontAwesome link to survive.

  • CDN reachability is a hard dependency.

    Baselines + comparison now depend on Google Fonts. Re-vendoring is forbidden, so an offline runner is a blocker to raise — verified reachable here (HTTP 200).

03Decisions

Key decisions & options

Font embedding mechanism

Locked

Scoped Google-Fonts <link> for Barlow Semi Condensed only, beside the existing DS-CDN link. No vendoring; the four Gotham .otf are deleted.

Link the full design-system.css as the font source — couples the font load to layout/color tokens and Vollkorn, out of scope.

Weight mapping (resolved in research)

Chosen

Map up, not 1:1, because Barlow is lighter/narrower than Gotham at equal nominal weight: default text = 900 upright, default logo = 800, italic preload = 900 italic, Book equivalent = 400.

Four self-hosted @font-face aliases mapping to Barlow weights — re-introduces a CSS layer; numeric weight matches the Google Fonts / DS model.

CI/local network access to Google Fonts

Risk

Baseline regen and pixel comparison now require fonts.googleapis.com / fonts.gstatic.com. Verified reachable here (HTTP 200); if a runner is offline it is a blocker to raise — never re-vendor (workspace rule).
