Gotham Narrow → Barlow Semi Condensed

Issue: z6qfk · Generated 2026-06-03

01Strategy

Read this first — the rest is detail.

Strategy summary

Gotham Narrow was modeled as four separate font-family names; Barlow Semi Condensed is one family with numeric weights. The code picks fonts only by fontFamily string — so switching the family name alone renders Barlow 400, not the heavy 900/800 we want. The fix: set the family to "Barlow Semi Condensed" everywhere AND pass an explicit fontWeight (and fontStyle for italic) to Fabric.js.

  • One family, explicit weights.

    Default text → 900 upright; default logo → 800. Don't fake four families.

  • Tests render the production build, not dev HTML.

    Playwright runs make serve-build → build/. The Google-Fonts <link> must survive build.js's CSS-link rewrite, so place it beside the design-system CDN link (outside the replaced span).

  • No font picker remains.

    The #font-style-select dropdown was already removed; text font is hardcoded at event-handlers.js:141. No UI option strings to change.

  • All affected baselines must be regenerated.

    Barlow is narrower → line breaks/textbox sizes shift. Run npm run generate-references; visual sign-off is an acceptance criterion.

03Decisions

Key decisions & options

Font embedding source

Locked

Scoped Google-Fonts <link> for only Barlow Semi Condensed (ital,wght 0,400;600;700;800;900;1,400;1,900&display=swap). Family name exactly "Barlow Semi Condensed".

Link full design-system.css as the font source — rejected: pulls layout/color tokens, widens scope.

One family + fontWeight vs four alias families

Chosen

Single family "Barlow Semi Condensed"; select heaviness via Fabric fontWeight. Matches the Google-Fonts model and the design system.

Four self-hosted alias @font-face families mapping to Barlow weights — re-introduces a CSS layer and complexity.

Weight mapping

Recommended

Ultra (default text) → 900 upright; Bold (default logo) → 800 (not 700, to keep hierarchy vs 900 text); Ultra Italic → 900 italic; Book → 400. Barlow is lighter/narrower than Gotham, so map up.

Open: visual sign-off decides if 900 reads too light vs Gotham Ultra — there is no heavier step, so logo=800 is the hierarchy lever.

Google-Fonts <link> placement

Risk

Place beside the design-system CDN link (or before the FontAwesome link) so build.js's CSS-link replace regex does not delete it. Verify with grep googleapis build/index.html after build.

CI network dependency on Google Fonts

Open

Visual regression now depends on the CDN. If CI runs offline, baselines/diffs break — and re-vendoring is forbidden by workspace rule. Flag as a plan risk.
